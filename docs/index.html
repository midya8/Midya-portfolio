taglab

TagLab: the normalizer is part of the model

TagLab trains linear-chain conditional random fields from scratch, with no tensor library, autodiff, model API or external dataset. A 39-parameter sequence score combines fixed observed features, FROM/TO label transitions and separate start/end scores. Manual log-space forward/backward produces the global partition, node and adjacent-label marginals.
