A 39-parameter sequence score combines fixed observed features, FROM/TO label transitions and separate start/end scores. Manual log-space forward/backward produces the global partition, node and adjacent-label marginals.

TokenForge: same merges, different work

Optional occurrence-indexed BPE training with exact original merges and saved artifacts.
