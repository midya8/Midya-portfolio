# Midya Rahmani

Toronto-based technologist with 12+ years across technology, financial services and telecommunications. Lately I spend most of my build time on large language models, agentic systems and workflow automation.

I learn by building things myself. Most of the repos below are small, self-contained projects: implement an idea from scratch, test it properly, and write down what actually happened, including the experiments that didn't work. Everything runs offline with no API keys or model downloads. I wrote up the habits behind them in [approach.md](approach.md).

## A few I'd start with

- [scratchgpt](https://github.com/midya8/scratchgpt): a GPT built and trained in pure NumPy, with its own tiny autograd and hand-written backprop.
- [ml-from-scratch](https://github.com/midya8/ai-portfolio): my monorepo of about 40 smaller builds, including a NumPy transformer, FlashAttention, LoRA/QLoRA, a [Mamba-style SSM](https://github.com/midya8/ai-portfolio/tree/main/mamba-numpy), sparse autoencoders, plus LLM tooling like evals, RAG and agents.
- [mixture-of-experts](https://github.com/midya8/mixture-of-experts): sparse expert routing, load balancing and what goes wrong when it collapses.
- [speculative-decoding](https://github.com/midya8/speculative-decoding): draft-and-verify decoding that keeps the target model's output unchanged.
- [lora-finetuning](https://github.com/midya8/lora-finetuning): low-rank adapters on a frozen model, and how much rank you actually need.
- [preference-optimization](https://github.com/midya8/preference-optimization): a tiny RLHF loop with a Bradley-Terry reward model and a KL-regularised policy.
- [ppo-numpy](https://github.com/midya8/ppo-numpy): PPO for CartPole in NumPy.
- [mamba-lite](https://github.com/midya8/mamba-lite): A Mamba-style selective SSM with a hand-written NumPy autograd engine, trained on a selective copy task where the fixed-rate ablation never completes a single sequence. ([case study](projects/mamba-lite.md))
- [ddpm-mini](https://github.com/midya8/ddpm-mini): A diffusion model trained from scratch in NumPy, scored with 1-NN separability, where the stochastic samplers pass and deterministic DDIM visibly does not. ([case study](projects/ddpm-mini.md))
[realnvp-numpy](https://github.com/midya8/realnvp-numpy): A normalizing flow trained from scratch in NumPy, with exact likelihood, hand-written backprop, and the same 1-NN check as ddpm-mini.
[lstm-numpy](https://github.com/midya8/lstm-numpy): A character-level LSTM trained from scratch in NumPy with hand-written BPTT, which closes 195 of 200 sampled brackets where an n-gram closes 57.
[tsne-numpy](https://github.com/midya8/tsne-numpy): t-SNE written from scratch in NumPy with hand-written gradients, keeping 0.55 of each point's ten nearest neighbors where PCA-2 keeps 0.12.
[ica-numpy](https://github.com/midya8/ica-numpy): FastICA written from scratch in NumPy, unmixing four sources from four random mixtures at 0.9997 mean correlation where PCA keeps 0.53.
- [evalforge](https://github.com/midya8/evalforge): local evaluation for LLM and agent outputs, with regression gates for CI.
- [agenttrace](https://github.com/midya8/agenttrace): validation, analysis and HTML reports for agent execution traces.
