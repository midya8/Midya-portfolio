- **TagLab** - Manual linear-chain conditional random fields with analytic likelihood gradients, log-space messages and all 327 optimization states replayed, built from scratch — it makes the normalizer part of the model instead of letting a library hide what the partition function does: a 39-parameter sequence score combines fixed observed features, FROM/TO label transitions and separate start/end scores; manual log-space forward/backward produces the global partition, node and adjacent-label marginals, and expected-minus-observed feature counts give the supervised conditional-likelihood gradient, with Viterbi and token-marginal decisions kept separate. The independent-label control uses exactly the same eight observed features including left/right context, its 15 sequence scores fixed at zero and its remaining 24 weights fitted, so it is a fitted competitor rather than a weak untrained baseline; both families fit three positive L2 penalties and select by validation conditional NLL per token. The losing metric stays visible: the selected chain's test NLL/token is 0.557614 against the independent control's 0.813715, but its Viterbi token errors are worse, 66/164 against 56/164, while marginal token errors tie at 56/164 and whole-sequence errors tie at 15/16 — a better distribution score and a worse best path are different objectives, and the family comparison changes fitted parameters and penalty geometry too, so it is descriptive rather than an isolated causal effect. The fixture is 24 training, 12 validation and 16 test sequences of noisy numeric observations from persistent synthetic states, with seeds, complete examples and labels retained. Every one of 327 stored states retains all parameters, all 39 analytic gradient entries, objective, gradient norm, accepted Armijo step and rejected larger steps; the browser independently recomputes objective and gradient from the original training examples. Three fits stop at the 1e-5 gradient tolerance and three exhaust their 80-update budget; the selected chain exhausts its budget with gradient norm about 0.000629, and convexity plus a decreasing curve do not certify that finite iterate as an optimum. An exact normalization witness keeps the global-versus-local distinction concrete: three allowed paths A/C, B/A and B/C have raw weights [1/9,1,1/9], one global normalizer gives [1/11,9/11,1/11] while equal initial branch scores and local outgoing normalizers give [1/2,9/20,1/20], with five evidence weights computed in exact fractions. V0.2 adds hypothetical label-event conditioning: an allowed label subset at each position, fitted scores fixed, event mass plus conditional node/pair/path witnesses, all 39 log-event derivatives, an empty allowed set exactly impossible with no invented conditional distribution, and a possible rare event whose finite log probability underflows to zero in floating point, distinguished from zero support — 3,336 event witnesses and 4,647 browser states overall, with 31 Python and 12 Node/real-Chrome tests at v0.2. V0.3 adds auditable backward-conditional joint path sampling with a paired independent-node control using the same supplied uniforms; exact pair probabilities and total variation stay separate from descriptive frequencies of 64 seeded draws, each reverse step retaining its probabilities, log probabilities, uniform, CDF, chosen bin and numerical flags. V0.4 adds nonlocal occurrence-count events: the count inspector conditions on exactly r occurrences of a chosen label, and an augmented (count, label) forward/suffix recursion exposes the full original count distribution and reconstructs conditional node/pair probabilities, entropy, a complete best path and all 39 event derivatives — counts are positions, not runs or segments. An independent fair two-position control conditioned on exactly one A permits only AB and BA, each with mass 1/2; node marginals remain halves, but independent draws from them leave the event half the time, and the inspector separately computes the independent-node Poisson-binomial count law — conditioning can create dependence without transition scores, and a correct expected count does not guarantee a valid complete path. 43 Python and 20 Node/Chrome tests cover 600 events per enumerator across sixty fixtures in independent Fraction and BigInt path enumerators, all 39 finite-difference event derivatives, 864 cross-language numerical witnesses and 864 browser queries; the inspectors total 5,895 UI states/queries, and the original v0.1 suite's 22 Python and seven Node tests cover 60 rational path-potential controls, all 39 finite differences, 12,753 scalar gradient checks and 32 complete selected-model sequence witnesses, with real Chrome exercising 327 optimizer states plus 984 model/sequence/focus states. - **SpectralLab** - Normalized spectral clustering with manual affinity/Laplacian/k-means code and explicitly disclosed NumPy eigensolves, built from scratch — it makes the graph the visible choice instead of letting a scatter plot hide which points are neighbors and what their connection means: the affinity and normalized Laplacian are built explicitly, the eigenspace is retained, every row is normalized and manual k-means runs on the embedding, with NumPy supplying only the symmetric eigenvalue solve through LAPACK. The browser reconstructs all graph weights and every selected point's degree, neighbors, cut contributions and three eigenpair equations, with original coordinates and row-normalized embedding side by side; any actual archived graph or point can be selected, colors or a display-only edge threshold changed, and the full point witness exported as JSON — a threshold that hides an edge never changes the fit. Two original seeded 96-point fixtures use noisy interleaving arcs and concentric rings; nine fixed graph rules give 18 total fits — union/mutual kNN at 3/6/12 neighbors and full RBF at sigma .08/.25/1.0 — with raw-coordinate k-means alongside, two clusters and 12 starts fixed, least embedding inertia choosing only a k-means restart, and generator labels never choosing a graph or fit. The failures stay visible: moons union-3 reaches ARI 1.000 with eigengap .003156 while moons RBF sigma 1.0 gives ARI .242035 with the larger eigengap .350982 — a larger gap is not agreement with the intended classes, and raw-coordinate k-means gives the same .242035; rings union-6 reaches ARI 1.000 while rings union-12 gives ARI -.010195, so adding edges does not promise a better grouping; and moons mutual-3 has four disconnected components, so its two-dimensional truncation of a four-dimensional zero eigenspace is not unique and that fit is refused, with no arbitrary cluster labels shown. An original seven-vertex weighted graph has only 63 distinct nonempty binary cuts after fixing one cluster label; independent rational enumeration finds the optimum 3450/4181 = .8251614446304711, while the archived spectral relaxation plus k-means returns .860832137733142 — a worse cut, with both partitions and every weight visible, and no exact-optimality claim for the larger fixtures. V0.2 adds full degree-response derivatives and a basis-invariant projector tangent: a fixed undirected edge edit changes both endpoint degrees and every normalized incident edge, and manual differentiation retains those terms; the bottom-two spectral projector P = U Uᵀ has a basis-invariant derivative using only retained-to-excluded denominators, with internal repeated eigenvalues allowed and repeated eigenvalues crossing the retained boundary refused without an epsilon repair.
