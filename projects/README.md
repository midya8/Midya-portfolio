## AI systems

Local-first tools for evaluating, tracing, reviewing and planning LLM and agent workflows, plus vector search, decoding strategies and a transformer built from scratch.

- **PlanBench** - Validation and deterministic simulation of agent task plans: semantic DAG checks, seeded flaky-tool simulation with retries and skip cascades, makespan/cost/critical-path/parallelism metrics and CI gates. 29 unit tests.
  - Case study: [planbench.md](planbench.md)
  - Repo: [midya8/planbench](https://github.com/midya8/planbench)
- **DecodeLab** - Decoding strategies for language models from scratch: greedy, seeded temperature/top-k/top-p sampling and beam search over an exact n-gram distribution, with distinct-n/repetition/entropy metrics and CI gates. 36 unit tests.
  - Case study: [decodelab.md](decodelab.md)
  - Repo: [midya8/decodelab](https://github.com/midya8/decodelab)
- **VectorLite** - Exact and approximate kNN vector search from scratch: brute-force exact kNN (cosine and L2), seeded random-hyperplane LSH for approximate cosine search, and recall@k measured against the exact baseline with a CI gate. 31 unit tests.
  - Case study: [vectorlite.md](vectorlite.md)
  - Repo: [midya8/vectorlite](https://github.com/midya8/vectorlite)
- **GroundCheck** - Offline lexical grounding checks for answers against their sources: citation validation, per-sentence lexical support scoring, numeric consistency, JSON/Markdown reports and three CI gates. 43 unit tests.
  - Case study: [groundcheck.md](groundcheck.md)
  - Repo: [midya8/groundcheck](https://github.com/midya8/groundcheck)
- **TokenForge** - Byte-level BPE tokenizers trained from scratch: deterministic merge training, GPT-2-style pre-tokenization, exact round trips, JSON vocab persistence and compression statistics with a CI quality gate. 40 unit tests.
  - Case study: [tokenforge.md](tokenforge.md)
  - Repo: [midya8/tokenforge](https://github.com/midya8/tokenforge)
- **RetrievalBench** - Offline retrieval evaluation for RAG and search pipelines: exact BM25, token-window chunking with parent-document collapsing, graded qrels, recall@k/precision@k/MRR/nDCG@k, JSON/Markdown reports and CI quality gates. 42 unit tests.
  - Case study: [retrievalbench.md](retrievalbench.md)
  - Repo: [midya8/retrievalbench](https://github.com/midya8/retrievalbench)
- **ScratchGPT** - GPT built and trained from scratch in pure NumPy, with hand-written autograd, a pre-LN causal transformer, Adam training, sampling CLI and finite-difference gradient checks. 11 unit tests.
  - Case study: [scratchgpt.md](scratchgpt.md)
  - Repo: [midya8/scratchgpt](https://github.com/midya8/scratchgpt)
- **EvalForge** - Versioned JSONL task suites, deterministic scorers, adapter execution, persistent run artifacts, HTML/JUnit reports, Markdown run/regression job summaries, SARIF 2.1.0 output and baseline regression gates for LLM and agent outputs. 68 unit tests.
  - Repo: [midya8/evalforge](https://github.com/midya8/evalforge)
- **AgentTrace** - Validation, analysis, baseline/candidate comparison, escaped HTML timelines, JUnit XML reports, Markdown job summaries and SARIF 2.1.0 output for AI agent execution traces. 33 unit tests.
  - Repo: [midya8/agenttrace](https://github.com/midya8/agenttrace)
- **PromptGuard** - Secret, token, PII, prompt-injection and metadata linting for prompt files with redacted JSON/SARIF/JUnit XML/Markdown/HTML reports, CI gates and value-bound baseline suppression. 68 unit tests.
  - Case study: [promptguard.md](promptguard.md)
  - Repo: [midya8/promptguard](https://github.com/midya8/promptguard)

## Python utilities

Dependency-free, standard-library-only tools: a CLI for day-to-day use plus an importable library for automation, backed by unit tests and CI.

- **sre-toolkit** — Error-budget and burn-rate math, multi-window burn-rate alerting, rule-based alert triage, and Markdown SLO definitions, status reports, and postmortems. 254 unit tests.
  - Case study: [sre-toolkit.md](sre-toolkit.md)
  - Repo: [midya8/sre-toolkit](https://github.com/midya8/sre-toolkit)
- **loglens** — Access-log analysis for incident work: error rates, failing paths, 5xx sources, latency percentiles, incident timelines, and Markdown incident reports. Parses nginx/Apache combined and JSON logs. 241 unit tests.
  - Case study: [loglens.md](loglens.md)
  - Repo: [midya8/loglens](https://github.com/midya8/loglens)
- **flowkit** — Workflow runner: JSON-defined DAGs of shell commands with retries and exponential backoff, timeouts, fail-fast or continue-on-error semantics, parallel execution, conditional steps, end-phase hooks, dry-run plans, and text/JSON run reports. Standard library only, 123 unit tests.
  - Case study: [flowkit.md](flowkit.md)
  - Repo: [midya8/flowkit](https://github.com/midya8/flowkit)
- **uptimekit** — Synthetic uptime monitoring and availability reporting in pure Python, no dependencies and no database: HTTP, TCP connect, and TLS certificate-expiry probes, an append-only JSONL history, availability roll-ups with latency percentiles, incident detection with a consecutive-failure flap guard and a sustained-outage gate, SLO measurement (error budget consumed, met-or-breached status, --fail-slo exits 1 on a breach), a watch mode for hosts without cron, and a self-contained HTML status page. 98 unit tests running fully offline, CI on Python 3.11.
  - Case study: [uptimekit.md](uptimekit.md)
  - Repo: [midya8/uptimekit](https://github.com/midya8/uptimekit)
